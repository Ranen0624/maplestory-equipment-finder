개인정보 처리방침

최종 수정일: 2026-09-22 · 공개 배포판 2.0.1 기준

웹사이트별도 회원가입을 요구하지 않으며 이름, 전화번호, 주민등록번호 등 직접 식별정보를 서비스 기능상 수집하지 않는 것을 원칙으로 합니다.
NEXON API Key홈페이지에서는 API Key를 입력받지 않습니다. 공개 배포판에서 사용자가 입력하고 저장한 Key는 Windows 사용자 설정(QSettings)에 보관되며 두 검색기의 NEXON Open API 요청에 함께 사용됩니다. 프로그램의 로그아웃 기능으로 저장된 Key를 삭제할 수 있습니다.
캐릭터 정보캐릭터명, 월드, 레벨, 직업, 장비 등 NEXON Open API가 공개적으로 제공하는 범위의 게임 데이터를 조회합니다.
로컬 데이터검색 조건, 진행상황, 공개 API 응답 캐시와 결과 파일은 사용자의 PC에 저장될 수 있습니다.
제3자 제공홈페이지 운영자가 API Key나 검색 결과를 별도 서버에 수집해 판매하거나 광고 목적으로 제공하도록 설계된 서비스가 아닙니다.

외부 서비스

홈페이지는 GitHub Pages 등 정적 호스팅 환경에서 제공될 수 있으며 호스팅 사업자가 보안·운영 목적으로 접속 로그를 처리할 수 있습니다. 실제 게임 데이터 검색 요청은 데스크톱 앱에서 NEXON Open API로 전송됩니다.

비공식 서비스 고지

본 프로그램과 홈페이지는 NEXON 및 메이플스토리의 공식 서비스가 아닙니다. 게임, 상표, 공개 데이터에 관한 권리는 각 권리자에게 있습니다.
