NEXON Open API 방문 ↗
01

다운로드하고 실행

Windows용 ZIP 파일을 내려받아 압축을 풀고 Run_MapleTools.vbs를 실행하세요. 첫 실행에는 필요한 구성 요소를 준비합니다.

02

공통 API Key 설정

NEXON Open API에서 발급받은 키를 프로그램 설정에 저장하세요. 한 번 설정하면 두 검색기에 함께 적용됩니다.

03

조건을 넣고 검색

장비 옵션이나 캐릭터 조합을 입력하세요. 결과에서 상세 정보를 확인하고, 필요한 목록은 CSV로 저장할 수 있습니다.

궁금한 점이 있나요?

웹사이트에서 바로 실제 검색할 수 있나요?

홈페이지의 웹 체험판은 입력한 조건을 가상 예시 데이터와 비교합니다. 실제 캐릭터 검색은 Windows 프로그램에서 실행하며, 홈페이지에서는 API Key를 입력받거나 검색 API를 호출하지 않습니다.

검색한 캐릭터가 나오지 않는 이유는 무엇인가요?

입력한 조건, 기준일, 공개 데이터 제공 범위에 따라 결과가 달라집니다. 유니온 챔피언 검색은 공개된 유니온 챔피언 등록 캐릭터를 비교하므로 등록되지 않은 캐릭터는 매칭되지 않을 수 있습니다.

기준일과 검색 범위는 어떻게 설정하나요?

프로그램에서는 기준일과 월드, 레벨·직업 조건을 설정할 수 있습니다. 당일 데이터는 갱신 시점에 영향을 받을 수 있어 전날 기준 조회를 권장합니다. 검색 범위가 넓을수록 조회 시간이 길어질 수 있습니다.

프로그램이 실행되지 않으면 어떻게 하나요?

ZIP을 완전히 압축 해제했는지 먼저 확인하세요. 첫 실행 시 구성 요소 설치에 인터넷 연결이 필요할 수 있습니다. 실행 문제를 확인하려면 같은 폴더의 debug_run.cmd를 실행하세요.

API Key는 어디에 저장되나요?

배포용 프로그램에 입력한 키는 Windows 사용자 설정에 저장되어 두 검색기가 함께 사용합니다. 프로그램에서 로그아웃하면 저장된 키가 삭제됩니다.
