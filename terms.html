GUIDE & NOTICE

이용안내

공개 장비 검색 도구의 범위와 주의사항입니다.

서비스 성격

메이플 장비 검색기는 NEXON Open API가 제공하는 공개 데이터를 조건별로 조회하고 비교하기 위한 비공식 Windows 도구입니다. 검색 결과는 API 제공 상태, 기준일, 랭킹 데이터의 갱신 시점에 따라 달라질 수 있습니다.

데이터 및 정확성

프로그램은 공개 API 응답을 기반으로 필터링합니다. 과거 데이터가 존재하지 않는 날짜는 건너뛸 수 있으며, 오늘/전일 데이터는 API 제공 시간에 따라 지연될 수 있습니다. 결과는 참고용으로 사용해 주세요.

API 이용

공개 배포판은 사용자가 발급받은 NEXON Open API Key를 사용합니다. 과도한 호출 방지를 위해 호출 간격, 429 대기, 체크포인트 및 캐시 기능을 포함합니다. NEXON Open API 정책과 이용약관을 준수해 사용해야 합니다.

비공식 프로젝트

본 프로젝트는 NEXON 및 메이플스토리의 공식 서비스가 아닙니다. 메이플스토리 및 관련 상표·게임 데이터의 권리는 해당 권리자에게 있습니다.
