# MapleTools 홈페이지

메이플 장비 검색기와 유니온 챔피언 검색기를 소개하는 반응형 홈페이지입니다.

## GitHub Pages에 반영

1. 기존 저장소를 백업한 뒤, 이 패키지의 내용물 전체를 기존 Pages 배포 폴더에 복사합니다.
2. Pages가 저장소 루트에서 배포된다면 루트에, `docs/`에서 배포된다면 `docs/` 안에 복사합니다. 기존에 별도 빌드가 있다면 아래 파일을 그 배포 결과물에 통합합니다.
3. 커밋 후 기존 GitHub Pages 배포가 완료되면 홈페이지를 확인합니다.

모든 내부 경로는 상대 경로입니다. `[https://ranen0624.github.io/maplestory-equipment-finder/](https://ranen0624.github.io/mapletools/)`처럼 하위 경로에서도 작동합니다. 프레임워크, 빌드, 외부 CDN이 필요하지 않습니다. 로컬에서는 `index.html`을 브라우저에서 열어 볼 수 있습니다.

## 구성

- 반짝이는 별빛, 부유 아이콘, 스크롤 등장 효과, 카드 조명
- 직접 입력하고 클릭하는 HTML 웹 체험판 (`demo.html`, `demo.css`, `demo.js`)
- 통합 홈, 장비 검색 조건 5개 영역, 유니온 캐릭터 6개 조합, 예시 결과와 상세보기
- 검색 조건 비교, CSV 내보내기, 진행 로그, 설정 연결 예시
- 모바일 메뉴, FAQ, 키보드 조작, 동작 줄이기 설정 지원
- 배포용 Windows ZIP 다운로드

## 웹 체험판 안내

체험판 상단과 홈페이지 체험 영역에 다음 문구를 표시합니다.

> 실제 프로그램과 기능과 Ui가 다를 수 있습니다. 기능설명을 위한 예시입니다.

실제 프로그램의 통합 홈, 메뉴, 조건 입력 배치를 참고해 웹용으로 구성했습니다. 장비와 유니온 검색은 내장된 가상 예시 데이터에 사용자가 입력한 조건을 적용합니다. 실제 캐릭터 조회, API 연결, 키 저장은 수행하지 않습니다. 날짜와 설정 연결, 타임라인, 코디 기록은 기능 설명용 예시입니다.

기존 안내 영상과 해당 캡처 파일을 사이트에서 제거했습니다. 체험판 HTML/CSS/JavaScript는 약 40KB이며 이미지는 홈페이지와 같은 WebP 리소스를 사용합니다. 체험판은 지연 로드됩니다. 이미지 등 초기 파일 전송 외에 검색으로 추가 네트워크 요청을 만들지 않습니다.

## 다운로드 파일

`downloads/MapleTools_2.0.1_Windows.zip`은 제공된 배포용 통합 ZIP을 파일명만 바꾼 것입니다. PERSONAL 버전은 포함하지 않았습니다. 다운로드 파일을 갱신할 때 `index.html`의 링크와 버전 표기도 함께 수정하세요.

## 리소스

제공된 통합 프로그램의 로고, 두 검색기 아이콘과 일러스트, 성과 달빛 배경, 공식 앱 아이콘을 재사용했습니다. 페이지용 이미지는 용량을 줄인 WebP입니다. 원본 프로그램 ZIP은 수정하지 않았습니다. 신규 생성 이미지가 없어도 제공된 리소스로 구성할 수 있었습니다.

## 적용 상태

기존 GitHub 저장소의 main 브랜치 소스(1f5b99a)를 확인하여 기존 개인정보 처리방침·이용안내·다운로드 경로와 이전 배포 파일을 유지했습니다. 메인은 MapleTools 2.0.1로 개편했고 개인정보 안내에 공통 API Key 저장 방식을 반영했습니다. GitHub에 푸시하거나 실제 홈페이지를 배포하지는 않았습니다.

개발용 미리보기는 `npm ci` 다음 `npm run dev`로 실행할 수 있습니다. 배포는 빌드 없이 정적 파일 그대로 가능합니다.
