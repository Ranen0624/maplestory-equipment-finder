# 메이플 장비 검색기 1.2.1

NEXON Open API 기반의 비공식 Windows 장비 조건 검색 도구와 GitHub Pages 소개 사이트입니다.

## 공개 배포 파일

- `downloads/MaplestoryEquipmentFinder_1.2.1_Windows.zip` — 정식 공개 배포판
- SHA-256: `e5cdf4bd35f428f04e4f43833b70af22b1d70f2cf87fb98ccb557cc36a3271a3`

GitHub 공개 저장소에는 **정식 배포판만** 포함합니다.

## 주요 기능

- 조회일 / 레벨 / 직업 / 월드 조건 검색
- 장비명 / 스타포스 검색
- 잠재능력 / 에디셔널 잠재능력 / 추가옵션 필터
- 검색 체크포인트 / 이어하기 / 429 자동 대기
- 검색 결과 CSV 저장
- 캐릭터 상세창 / 타임라인 / 코디 기록
- 메인 탭 도움말
- 하단 고정 검색 진행률

## GitHub Pages 배포

이 폴더의 **내용물 전체를 저장소 루트**에 업로드한 뒤 GitHub Pages에서 `Deploy from a branch` → `main / root`를 선택하면 됩니다.

```text
index.html
privacy.html
terms.html
download.html
style.css
.nojekyll
assets/
downloads/
```

이 프로젝트는 NEXON 및 메이플스토리의 공식 서비스가 아닙니다. 게임 및 관련 상표·데이터의 권리는 각 권리자에게 있습니다.
